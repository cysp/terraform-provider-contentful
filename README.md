# Terraform Provider Contentful

Manage content models, Entries, and settings in existing Contentful spaces. The provider also manages organization resources, including teams and App Definitions, and account credentials.

[![Version](https://img.shields.io/github/v/release/cysp/terraform-provider-contentful?display_name=tag&sort=semver&logo=terraform&label=version)](https://registry.terraform.io/providers/cysp/contentful)

## Use the provider

[Configure the provider](https://registry.terraform.io/providers/cysp/contentful/latest/docs) with a Content Management API token. The Terraform Registry has the resource reference, import examples, and guides for each release. For the version in this checkout, see the [provider overview](docs/index.md) and [examples](examples/).
